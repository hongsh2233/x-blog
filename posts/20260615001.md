# 🚀 [Tech News] Chrome 149, AI 에이전트를 위한 웹 표준 'WebMCP' 오리진 트라이얼 시작!

Google이 브라우저 기반 AI 에이전트가 웹사이트를 도구(Tool)처럼 직접 호출하고 제어할 수 있도록 돕는 새로운 웹 표준 제안, **WebMCP(Web Model Context Protocol)**의 오리진 트라이얼(Origin Trial)을 Chrome 149 버전부터 시작합니다.

---

## 💡 WebMCP란 무엇인가요?

지금까지의 AI 에이전트는 웹사이트를 사람처럼 이용해야 했습니다. 화면을 스크린샷으로 찍어 시각적으로 분석하거나, 복잡하고 부서지기 쉬운 DOM(HTML 구조) 트리와 CSS 선택자를 크롤링하여 '제출' 버튼이 어디 있는지 '추측'해야 했습니다. 이는 속도가 느릴 뿐만 아니라, UI가 조금만 바뀌어도 에이전트가 오작동하는 원인이 되었습니다.

**WebMCP**는 이 문제를 해결하기 위해 웹사이트가 AI 에이전트에게 **기계 읽기 가능하고(Machine-readable) 구조화된 도구(함수, 폼 등)를 직접 제공**할 수 있도록 하는 브라우저 표준 API입니다.

* **기존 방식:** 에이전트가 UI를 보고 "이 버튼이 결제 버튼이겠지?" 하고 추측 및 클릭
* **WebMCP 방식:** 웹사이트가 에이전트에게 `"정확한 입력 매개변수를 가진 결제 함수(JavaScript)"`를 명확히 제공하여 에이전트가 이를 직접 실행

---

## 🛠️ 핵심 기능 및 제공 API

WebMCP는 웹 에이전트가 사용자 대신 안전하고 정교한 작업을 수행할 수 있도록 두 가지 형태의 API 표면을 제공합니다.

1.  **선언적(Declarative) API**
    * HTML 폼(Form) 엘리먼트에 직접 표준 작업을 정의하여 에이전트가 상호작용할 수 있게 합니다.
2.  **명령형(Imperative) API**
    * JavaScript 실행이 필요한 복잡하고 동적인 상호작용을 처리합니다. 이름, 설명, JSON 스키마를 가진 도구(Tool)를 등록하면 브라우저 내 AI 에이전트가 이를 발견하고 호출합니다.

---

## 🎯 주요 활용 사례 (Use Cases)

* **복잡한 구조화된 폼 자동 입력:** 기존의 단순 자동완성(Autofill)을 넘어, 성/이름을 분리해야 하는지 풀네임을 입력해야 하는지 등을 에이전트가 정확히 매핑하여 폼을 채웁니다.
* **효율적인 애플리케이션 디버깅 및 진단:** 깊숙이 숨겨진 메뉴나 복잡한 달력 UI 등을 에이전트가 개발자 설정 페이지의 진단 도구를 통해 직접 트리거하고 문제를 해결합니다.
* **끊김 없는 고속 에이전트 워크플로:** 항공권 예약, 티켓 제출, 복잡한 데이터 탐색 시 화면 렌더링을 기다리지 않고 필요한 API와 기능을 직접 호출하므로 프로세스가 획기적으로 빨라집니다.

---

## 🔒 보안 및 격리 (Security)

AI 에이전트에게 사이트 제어권을 주는 만큼 보안이 매우 강력하게 설계되었습니다.
* **오리진 격리(Origin Isolation) 필수:** WebMCP는 도구의 수명 동안 안정적인 오리진이 보장되는 문서에서만 활성화됩니다 (`document.domain` 사용 시 비활성화).
* **권한 정책(Permissions Policy):** 기본적으로 `self`로 제한되며, 교차 오리진(Cross-origin) iframe에서 사용하려면 `allow="tools"` 속성을 명시해야 합니다.
* **힌트 제공:** 신뢰할 수 없는 사용자 생성 콘텐츠(UGC) 데이터 반환 시 `untrustedContentHint`를, 상태를 변경하지 않는 도구에는 `readOnlyHint`를 설정해 에이전트가 유저에게 확인 창을 띄울지 판단하도록 도울 수 있습니다.

---

## 🏃 어떻게 참여하고 테스트하나요?

현재 WebMCP는 프로토타이핑 단계를 위한 **오리진 트라이얼 단계**입니다. 

* **로컬 환경에서 미리 테스트하기:**
    1. Chrome 브라우저 주소창에 `chrome://flags/#enable-webmcp-testing` 입력
    2. 해당 플래그를 **Enabled**로 변경 후 브라우저 재시작
* **실제 서비스(라이브 환경)에서 테스트하기:**
    * Chrome 개발자 프로그램을 통해 오리진 트라이얼에 등록하고, 토큰을 발급받아 사이트 헤더에 포함하면 실제 유저를 대상으로 실험할 수 있습니다.
